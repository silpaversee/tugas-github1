# C-Learn - Platform Belajar Pemrograman C

Repositori ini berisi berkas *source code* untuk proyek web **C-Learn**, sebuah website edukasi interaktif untuk mempelajari dasar-dasar bahasa pemrograman C.

## 📌 Deskripsi Proyek
**C-Learn** dirancang untuk membantu pemula memahami konsep dasar pemrograman C, mulai dari sintaks dasar, struktur kontrol alur (perulangan dan percabangan), manipulasi variabel, hingga implementasi logika program sederhana melalui antarmuka web yang bersih dan mudah dipahami.

## 🚀 Fitur Utama
- **Modul Pembelajaran:** Penjelasan materi dasar pemrograman C yang terstruktur.
- **Contoh Kode Program:** Potongan sintaks dan contoh kasus kode C siap pelajari.
- **Tampilan Interaktif:** Struktur antarmuka web semantik dan navigasi yang ramah pengguna.
