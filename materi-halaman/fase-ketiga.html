Perulangan (Looping)

09

↻ Mission Brief

Perulangan (looping) adalah perintah dalam Bahasa C yang digunakan untuk mengeksekusi instruksi tertentu secara berulang-ulang berdasarkan syarat kondisi tertentu.

🏗️ A. 3 Bagian Dasar Perulangan

Setiap struktur perulangan wajib memiliki 3 komponen utama berikut:

1
Initialization (Inisialisasi): Langkah awal membuat variabel penghitung (counter), biasanya dari 0 (contoh: int i = 0;).
2
Condition (Kondisi): Batas nilai agar perulangan berhenti (contoh: i < 10).
3
Final (Pengubah Nilai): Perintah penambah/pengurang nilai variabel (contoh: i++ atau i--).

🔄 B. Jenis-Jenis Perintah Perulangan

1. Perulangan while

Mengevaluasi kondisi terlebih dahulu sebelum mengeksekusi perintah. Wajib ada perintah final agar tidak terjadi infinity loop (perulangan tanpa akhir).

Contoh while Loop 
int i = 1;
while (i <= 5) {
    printf("Perulangan ke-%d\n", i);
    i++; // Final (increment)
}

2. Perulangan do-while

Menjalankan perintahnya terlebih dahulu minimal 1 kali, baru memeriksa kondisi di akhir. Wajib diakhiri titik koma ; setelah while(...).

Contoh do-while Loop 
int s = 0;
do {
    printf("Belajar do-while\n");
    s++;
} while (s < 5);

3. Perulangan for

Penulisan paling ringkas di mana initialization, condition, dan final ditulis dalam 1 baris.

Contoh for Loop 
for (int i = 0; i < 5; i++) {
    printf("Perulangan for ke-%d\n", i);
}

🪆 C. Perulangan Bersarang (Nested Looping)

Perulangan di dalam perulangan lain. Biasa digunakan untuk membuat pola atau memproses tabel/matriks.

• Chapter 10

Perintah Pelompatan (Jump Statement)

10

⚡ Mission Brief

Jump statement digunakan untuk memindahkan, melewati, atau memberhentikan alur perulangan dan percabangan dalam program.

🏃 A. 5 Jenis Perintah Pelompatan

1. break

Menghentikan perulangan atau switch-case secara langsung dan keluar dari alur loop.

2. continue

Melewati/mengabaikan sisa perintah di bawahnya dan langsung melanjutkan ke iterasi perulangan berikutnya.

3. goto

Memindahkan alur eksekusi program secara langsung ke baris kode ber-label yang ditentukan (goto label;).

4. return

Mengakhiri eksekusi suatu fungsi dan mengembalikan nilai ke bagian program yang memanggilnya.

5. exit(0)

Memberhentikan seluruh eksekusi program secara langsung dari titik mana saja. Membutuhkan #include <stdlib.h>.

• Chapter 11

Array (Larik)

11

📊 Mission Brief

Array adalah variabel yang dapat menyimpan lebih dari satu data dengan tipe data yang sama dalam satu nama variabel.

🔢 A. Struktur & Indeks Array

Sintaks pembuatan Array: tipe_data nama_array[ukuran];

⚠️ Aturan Indeks Array:

Indeks array selalu dimulai dari 0, bukan 1. Artinya elemen ke-1 berada di array[0], dan elemen terakhir berada di array[ukuran - 1].

Garbage Value: Mengakses nomor indeks yang melebihi ukuran array akan menghasilkan nilai sampah memori acak!

Contoh Penggunaan Array 
int prima[5] = {2, 3, 5, 7, 11};
printf("Elemen pertama: %d\n", prima[0]); // Output: 2

🍱 B. Array Multidimensi & String

Array Multidimensi: Array yang berisi array lain (Contoh Array 2D: int matriks[3][4];).

String: Sebenarnya adalah array dari karakter (char) yang elemen akhirnya diakhiri karakter NULL (\0).

• Chapter 12

Fungsi (Function)

12

🧩 Mission Brief

Fungsi memecah program besar yang rumit menjadi sub-program sederhana agar kode mudah dipelihara, hemat memori, dan tidak ditulis berulang-ulang (DRY).

⚙️ A. Perbedaan Fungsi dan Prosedur

Fungsi (Mengembalikan Nilai)

Memiliki return type (int, float, char) dan menggunakan perintah return untuk mengirim hasil kembali ke pemanggil.

Prosedur (Tanpa Nilai Kembalian)

Memiliki return type void yang artinya kosong, sehingga tidak mengembalikan data apapun.

📥 B. Parameter dan Argumen

1
Parameter: Variabel penampung dalam definisi fungsi (Contoh: void tambah(int a, int b)).
2
Argumen: Nilai nyata yang dikirim saat fungsi dipanggil (Contoh: tambah(7, 3);).
Contoh Fungsi dengan Parameter & Return 
#include <stdio.h>

int dapatkan_hasil_kali(int a, int b) {
    return a * b; // Mengembalikan hasil
}

int main() {
    int hasil = dapatkan_hasil_kali(7, 3);
    printf("Hasil: %d\n", hasil);
    return 0;
}

📜 C. Function Prototype (Prototipe Fungsi)

Pernyataan awal tentang nama fungsi, tipe kembalian, dan parameternya di bagian atas sebelum main, agar compiler mengenali fungsi yang diletakkan di bawah main().
