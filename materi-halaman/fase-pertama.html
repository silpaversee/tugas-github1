Pemahaman Dasar Logika & Algoritma

01

🎯 Mission Brief

Sebelum membuat program, programmer harus paham cara berpikir logis dan sistematis. Algoritma adalah dasar pemecahan masalah sebelum ditulis ke kode program.

🧠 A. Pengertian Logika dan Algoritma

Logika dan algoritma adalah dua hal yang tidak bisa dipisahkan:

💡 Logika

Upaya berpikir secara cermat, tepat, dan logis (dapat diterima oleh akal sehat).

⚙️ Algoritma

Langkah-langkah yang terstruktur dan logis untuk memecahkan suatu masalah.

📜 B. Sejarah Algoritma & Penemuan Angka 0

Kata algoritma berasal dari nama ilmuwan Persia: Abu Ja’far Muhammad bin Musa Al-Khwarizmi yang menulis buku Al-Jabr wal-Muqabalah pada tahun 825 M di era Khilafah Abbasiyah (Baitul Hikmah).

🏛️ Tokoh Utama: Al-Khwarizmi

Beliau dikenal sebagai Bapak Algoritma dan penemu Aljabar. Salah satu kontribusi utamanya adalah memperkenalkan angka 0 (nol) yang menjadi dasar kode biner (0 dan 1) komputer modern serta Aljabar Boolean (George Boole).

💡 C. Contoh Algoritma Logis vs Tidak Logis

Berikut adalah perbandingan contoh algoritma segelas kopi:

✅ Algoritma Logis (Benar)

  1. Siapkan gelas, sendok, kopi, gula, air panas.
  2. Masukkan kopi, gula, air panas ke gelas.
  3. Aduk dengan sendok sampai rata.
  4. Kopi siap diminum.

❌ Contoh Algoritma Salah

  1. Aduk dengan sendok sampai rata.
  2. Kopi siap diminum.

(Tidak logis karena bahan dan gelas tidak ada)

💻 Contoh Algoritma Komputer: Menghitung Luas Lingkaran

1
Komputer menetapkan pi = 3.14 (tetap).
2
Komputer menyiapkan variabel jari_jari dan luas.
3
Komputer meminta user memasukkan nilai jari_jari (Input).
4
Hitung: luas = pi × jari_jari × jari_jari (Proses).
5
Tampilkan hasil luas ke pengguna (Output).

⚙️ D. 5 Kriteria Algoritma yang Baik (Donald E. Knuth)

1
Memiliki Input: Minimal ada 1 masukan data.
2
Memiliki Output: Minimal ada 1 hasil keluaran.
3
Finite (Terbatas): Memiliki batas akhir proses (tidak berulang selamanya).
4
Definite (Pasti): Langkah dan tujuan jelas tanpa keraguan.
5
Efektif & Efisien: Hemat memori dan tidak melakukan hal sia-sia.

Flowchart dan Pseudocode

02

🔀 Mission Brief

Flowchart dan pseudocode berfungsi sebagai alat komunikasi antara programmer dengan non-programmer agar rancangan alur dapat dipahami bersama sebelum koding.

📐 A. Pengertian Flowchart

Flowchart (Diagram Alir) adalah gambaran visual dari algoritma yang menggunakan simbol-simbol standar untuk menunjukkan alur proses program.

🔷 B. Simbol-Simbol Utama Flowchart

📜 C. Ketentuan Pembuatan Flowchart

1
Harus memiliki Judul.
2
Tidak Boleh Menggantung: Semua simbol wajib saling terhubung.
3
Posisi Start di tengah paling atas, End di paling bawah.
4
Decision memiliki 2 jalur panah: True dan False.

📝 D. Pengertian & Contoh Pseudocode

Pseudocode adalah penulisan algoritma yang menyerupai kode program namun menggunakan bahasa yang mudah dipahami manusia. Tanda ← artinya menetapkan nilai.

Pseudocode: Menghitung Luas Lingkaran 
1. pi ← 3.14
2. INPUT jari_jari
3. luas ← pi × jari_jari × jari_jari
4. OUTPUT luas

• Chapter 03

Pemrograman (Programming)

03

💻 Mission Brief

Pemrograman adalah proses merancang dan membangun program komputer. Orang yang membuat program dinamakan Programmer.

🚀 A. Mengapa Harus Belajar Pemrograman?

1
Meningkatkan cara berpikir, kreativitas, dan problem solving.
2
Peluang kerja dan karier sangat tinggi.
3
Sarana berdakwah dan membangun sains/teknologi.
4
Memudahkan urusan umat dengan aplikasi bermanfaat.
5
Fleksibilitas kerja remote (bisa kerja dari mana saja).

🌐 B. Bahasa Pemrograman & Tingkatannya

Bahasa pemrograman dibagi menjadi 3 tingkatan:

1. Low-Level

Bahasa mesin (0 dan 1) yang dimengerti langsung oleh hardware.

2. Mid-Level

Bahasa C: Punya akses cepat ke mesin & sintaks terstruktur.

3. High-Level

Python, Java, JS: Sintaks sangat mirip bahasa manusia (Inggris).

⚡ C. Alur Pemrosesan Komputer

Alur utama komputer: Input ➔ Proses ➔ Output

Simbol Operator Matematika:

* untuk perkalian (×), / untuk pembagian (÷), dan . untuk titik desimal.

🏗️ D. 3 Struktur Dasar Pemrograman

1. Sequence (Runtutan)

Perintah dijalankan urut baris demi baris dari atas ke bawah.

2. Selection (Percabangan)

Pemilihan perintah berdasarkan syarat kondisi (if-else).

3. Loop (Perulangan)

Menjalankan perintah berulang kali sampai batas tertentu.

• Chapter 04

Konsep Dasar Pemrograman Bahasa C

04

🚀 Mission Brief

Bahasa C diciptakan oleh Dennis Ritchie tahun 1972 di Bell Labs. Bahasa C adalah induk dari berbagai bahasa populer modern!

⚡ A. Fitur-Fitur Utama Bahasa C

1
Prosedural: Kode dijalankan urut dari paling atas ke paling bawah.
2
Tingkat Menengah: Memiliki kecepatan manipulasi hardware mesin.
3
Cepat & Efisien: Berjalan langsung tanpa interpreter.
4
Portable: Bisa dijalankan di Windows, Linux, dan macOS.
5
Induk Bahasa Modern: Menginspirasi C++, C#, Java, PHP, JS.

🛠️ B. Compiler MinGW & Visual Studio Code

Compiler bertugas menerjemahkan kode Bahasa C menjadi file .exe. Pada Windows digunakan MinGW GCC.

📌 Langkah Singkat Setup Compiler:

  1. Download mingw-get-setup.exe lalu install ke C:\MinGW\.
  2. Centang paket mingw32-base-bin dan mingw32-gcc-g++-bin ➔ Apply Changes.
  3. Atur Environment Variables Path ke C:\MinGW\bin\.
  4. Cek di Command Prompt: gcc --version.

🏛️ C. Anatomi Program Bahasa C Pertama

Berikut adalah struktur sederhana program C Hello World:

main.c 
#include <stdio.h>

int main() {
    // Mencetak teks ke layar
    printf("Hello World!\n");
    
    return 0;
}

🔍 Penjelasan Komponen Penting:

  • #include <stdio.h>: Memanggil library standar input/output agar fungsi printf bisa dipakai.
  • int main() { ... }: Fungsi utama tempat kode dijalankan pertama kali.
  • printf("...");: Perintah untuk menampilkan tulisan ke layar.
  • ; (Titik Koma): Penanda akhir dari setiap pernyataan (statement). Wajib ada!
  • // Komentar: Catatan keterangan yang tidak akan dijalankan oleh komputer.
  • return 0;: Penanda bahwa fungsi main selesai tanpa error.
