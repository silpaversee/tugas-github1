• Chapter 05

Struktur Pemrograman Bahasa C

05

🚀 Mission Brief

Saat menulis kode (ngoding) dalam Bahasa C, perintah yang kita buat akan dijalankan secara urut dari paling atas ke paling bawah (Prosedural). Mari pahami bagian-bagian utamanya!

🛠️ A. Preprocessor Directives

Preprocessor adalah program yang memanipulasi kode sumber sebelum dikompilasi oleh komputer. Kode dipanggil menggunakan preprocessor directive yang diawali tanda pagar (#).

1. Preprocessor Directive pada Header (#include)

Digunakan untuk menyertakan library (perpustakaan kode) yang berisi perintah-perintah bawaan.

  • Standard Library bawaan C diawali <...>, contoh: #include <stdio.h>
  • Library buatan sendiri diapit tanda petik "...", contoh: #include "fungsi_saya.c"

📚 Standard Library Populer dalam Bahasa C:

1
<stdio.h>: Standard Input Output (printf, scanf, fgets).
2
<conio.h>: Console I/O (getch: baca tanpa tampil teks, getche: baca & tampilkan teks).
3
<string.h>: Manipulasi teks (strcpy, strlen, strupr, strlwr, strcmp, strcat, strrev).
4
<stdbool.h>: Pendeklarasian variabel bertipe boolean (bool).
5
<stdlib.h>: Konversi data & kontrol proses (atof, atoi, system("cls"), system("pause"), exit(0)).
6
<math.h>: Operasi matematika dasar & rumit (sqrt, pow, sin, cos, tan, M_PI).
7
<windows.h>: Fungsi Windows API (Sleep(detik), textcolor(), backgroundcolor()).

2. Preprocessor Directive pada Deklarasi Global (#define)

Digunakan untuk menggantikan setiap nama variabel tertentu dalam program dengan suatu nilai konstan sebelum program berjalan.

Contoh #define 
#define PI 3.14
#define sisi 4

🏛️ B. Fungsi Main (Program Utama)

Agar program dapat dijalankan otomatis, fungsi harus bernama main. Fungsi main artinya utama, yang berarti fungsi yang dipanggil dan dijalankan pertama kali.

void main()

Fungsi utama yang tidak mengembalikan nilai data apapun setelah selesai berjalan.

int main()

Fungsi utama yang mengembalikan data ber-tipe integer. Biasanya diakhiri dengan return 0; sebagai tanda sukses.

💬 C. Comment (Komentar Kode)

Komentar adalah teks yang diabaikan oleh compiler dan tidak akan dijalankan oleh komputer. Komentar digunakan sebagai referensi/keterangan catatan programmer.

Contoh Komentar dalam C 
int main() {
    // Ini adalah komentar 1 baris (single-line comment)
    printf("Assalamu'alaikum\n");

    /* Ini adalah komentar banyak baris
       (multi-line comment) yang terdiri
       dari beberapa baris */
    return 0;
}

• Chapter 06

Tipe Data, Variabel & Input Output

06

📦 Mission Brief

Tipe data adalah pengenal dari suatu variabel. Variabel adalah wadah penyimpanan data dalam memori komputer. Pembahasan ini juga mencakup escape sequence dan operasi input-output.

🏷️ A. Tipe Data & Format Specifier

Format specifier adalah kode ber-awalan persen (%) yang digunakan untuk membaca atau mencetak isi variabel sesuai tipe datanya.

Tabel Tipe Data & Format Specifier Utama:

%c
char (1 Byte): Karakter tunggal (Contoh: 'A', '7').
%s
char [] (String): Sekumpulan karakter (Contoh: "PUB").
%d
int (4 Byte): Bilangan bulat (-2147483648 s.d. 2147483647).
%f
float (4 Byte): Bilangan pecahan presisi 6 desimal.
%lf
double (8 Byte): Bilangan pecahan presisi 15 desimal.
%d
bool (1 Byte): Menghasilkan 1 (True) atau 0 (False).

📦 B. Variabel dan Konstanta

Variabel adalah wadah penampung data di memori. Data di dalamnya disebut nilai (value).

🏢 Analogi Loker

Bayangkan loker asrama kalian. Loker = Memori Komputer, Label Loker = Nama Variabel & Tipe Data, Barang di dalam Loker = Nilai (Value).

❌ Penamaan Variabel Tidak Valid

  • int 6bilangan; (Diawali angka 6)
  • int total bilangan; (Mengandung spasi)
  • int total-bilangan; (Pakai strip -)

✅ Penamaan Variabel Valid & Standar

  • int bilangan;
  • int bilangan_1;
  • int total_bilangan; (Pakai underscore _)

3 Operasi Pembuatan & Manipulasi Variabel:

  1. Declaration (Deklarasi): Menyatakan variabel tanpa nilai awal (Contoh: int bilangan;).
  2. Initialization (Inisialisasi): Menyatakan variabel sekaligus nilai awal (Contoh: int bilangan = 7;).
  3. Assignment (Penugasan): Mengubah nilai variabel (Contoh: bilangan = 3; atau bilangan += 2;).

🔒 Konstanta (Nilai Tetap):

Konstanta adalah variabel yang nilainya tetap dan tidak dapat diubah setelah diinisialisasi.

Contoh Konstanta 
const int bilangan = 7;

🔤 C. Escape Sequence

Escape sequence adalah urutan karakter yang diawali tanda backslash (\) untuk menampilkan karakter khusus:

\n : Newline (baris baru)

\t : Horizontal tab (tab spasi)

\a : Suara peringatan (bip/bell)

\\ : Mencetak backslash (\)

\' : Mencetak tanda petik tunggal

\" : Mencetak tanda petik ganda

Contoh Escape Sequence 
printf("Baris Pertama\nBaris Kedua");

📥 D. Input Output Program (printf, scanf, fgets)

Program menerima masukan pengguna dengan scanf() dan menampilkan hasil dengan printf().

Input Output Angka (scanf) 
#include <stdio.h>

int main() {
    int bilangan; // Deklarasi variabel
    
    printf("Masukkan angka: ");
    scanf("%d", &bilangan); // & = Ampersand untuk memasukkan nilai ke memori
    
    printf("Hasil Output: %d\n", bilangan);
    return 0;
}

💡 Membaca Teks Ber-spasi (fgets):

Fungsi scanf("%s", ...) hanya membaca kata pertama sebelum spasi. Untuk membaca teks yang mengandung spasi (kalimat), disarankan menggunakan fgets() agar lebih aman dari buffer overflow:

Input Teks Ber-spasi (fgets) 
char kalimat[50];
printf("Masukkan nama lengkap: ");
fgets(kalimat, sizeof(kalimat), stdin);
printf("Halo, %s", kalimat);

• Chapter 07

Operator dalam Bahasa C

07

➗ Mission Brief

Operator adalah karakter atau simbol khusus yang digunakan untuk melakukan operasi matematika, perbandingan, logika, dan pengisian data dalam Bahasa C.

⚖️ A. Operator Precedence (Prioritas Operator)

Operator Precedence adalah tingkatan prioritas mana operator yang dieksekusi terlebih dahulu oleh sistem (seperti kaidah *kalibatakur* dalam matematika).

Contoh Perhitungan Precedence:

Dalam ekspresi hasil = 4 + 2 * 3 - 1;, perkalian 2 * 3 = 6 dieksekusi lebih dulu, lalu 4 + 6 = 10, dan 10 - 1 = 9.

➕ B. Operator Aritmatika

Digunakan untuk melakukan operasi matematika dasar:

+ : Penjumlahan (a + b)

- : Pengurangan (a - b)

* : Perkalian (a * b)

/ : Pembagian (a / b)

% : Modulus / sisa hasil bagi (a % b)

📌 Catatan Penting :

  • Pembagian dua bilangan bulat (int / int) hasilnya berupa bilangan bulat juga (pecahan dibuang).
  • Operator Modulus (%) hanya bisa digunakan untuk bilangan bulat (int), tidak bisa untuk float atau double.

📝 C. Operator Penugasan (Assignment Operator)

Digunakan untuk mengisi atau meng-update nilai suatu variabel:

=
Mengisi variabel dengan nilai baru (Contoh: bilangan = 7;)
+=
Mengisi nilai lama ditambah nilai baru (Contoh: bilangan += 3;)
-=
Mengisi nilai lama dikurangi nilai baru (Contoh: bilangan -= 2;)
*=
Mengisi nilai lama dikali nilai baru (Contoh: bilangan *= 4;)
/=
Mengisi nilai lama dibagi nilai baru (Contoh: bilangan /= 2;)

🔍 D. Operator Perbandingan & Logika

Perbandingan (Comparison)

== : Sama dengan

!= : Tidak sama dengan

> : Lebih dari

< : Kurang dari

>= : Lebih dari sama dengan

<= : Kurang dari sama dengan

Logika (Logical)

&& (AND) : True jika semua syarat benar.

|| (OR) : True jika salah satu syarat benar.

! (NOT) : Menandakan negasi / kebalikan.

⚠️ Bedakan:

Penugasan menggunakan = (satu tanda), sedangkan perbandingan menggunakan == (dua tanda sama dengan).

➕ E. Operator Tunggal (Unary Operator)

Operator yang hanya bekerja pada satu nilai/variabel saja:

  • ++ (Increment): Menambah 1 nilai pada variabel (Contoh: i++ atau ++i).
  • -- (Decrement): Mengurangi 1 nilai pada variabel (Contoh: i-- atau --i).

• Chapter 08

Percabangan (Decision)

08

🔀 Mission Brief

Percabangan (decision) adalah instruksi dalam Bahasa C yang digunakan untuk menentukan kelompok perintah mana yang akan dijalankan berdasarkan hasil evaluasi kondisi (True / False).

⚖️ A. Aturan Pembuatan Kondisi

Kondisi akan bernilai True (1) atau False (0). Contoh penulisan kondisi:

1
Mengecek angka nol: (angka == 0)
2
Positif / Negatif: (angka > 0) atau (angka < 0)
3
Genap / Ganjil: (angka % 2 == 0) atau (angka % 2 != 0)
4
Memeriksa String: (strcmp(input_nama, "PUB") == 0)
5
Lebih dari 1 syarat: (angka > 0 && angka % 2 == 0)

🌿 B. Jenis-Jenis Perintah Percabangan

1. Struktur if, else if, dan else

Pilihan cabang bertingkat berdasarkan kondisi:

Contoh if - else if - else 
if (bilangan > 0) {
    printf("Bilangan Positif\n");
} else if (bilangan < 0) {
    printf("Bilangan Negatif\n");
} else {
    printf("Angka Nol\n");
}

2. Struktur switch-case

Digunakan untuk memilih dari nilai-nilai konstan (tetap/pasti) bertipe integer atau char.

Contoh switch-case (Hari) 
switch(nomor) {
    case 1:
        printf("Hari Senin\n");
        break; // Menghentikan agar tidak lanjut ke case bawah
    case 2:
        printf("Hari Selasa\n");
        break;
    default:
        printf("Nomor Invalid\n");
}

3. Operator Ternary (Percabangan 1 Baris)

Penulisan ringkas dengan sintaks: kondisi ? perintah_true : perintah_false;

Contoh Ternary 
bilangan % 2 == 0 ? printf("Genap") : printf("Ganjil");

🪆 C. Percabangan Bersarang (Nested Decision)

Percabangan bersarang adalah struktur percabangan yang memiliki percabangan lain di dalam blok kodenya.
